# WorkSphere

A multi-tenant workforce management SaaS platform built using Spring Boot and PostgreSQL, featuring JWT Authentication, Role-Based Access Control (RBAC), Tenant Isolation, and Leave Management capabilities.

---

## Overview

WorkSphere is a backend-focused SaaS application designed to help organizations manage users, roles, tenants, and employee leave workflows securely.

The application follows a multi-tenant architecture, ensuring that each organization operates within its own isolated environment while sharing the same application infrastructure.
